# Knowledge base for the agent's retrieval (RAG)

The six notes here are **author-written sample notes**, not official guidance. They exist so the retrieval pipeline has content to work with, and they are written cautiously (no legal figures).

To make the agent's advice rest on real guidance, add consumer-protection and financial-literacy publications (for example guides from the CFPB, a national regulator or your bank) to this folder as `.md`, `.txt` or `.pdf` (PDF needs `pip install pypdf`), then re-run section 6.2 of the notebook. Files whose names start with a number are cited without the number (`[reporting_unauthorized#2]`).
Respect each publication's license and keep the source URL and access date in the file.
